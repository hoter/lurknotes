# Хоткей поднимает окно: единый экземпляр и D-Bus-активация

Type: grilling
Status: resolved
Blocked by: 02

## Question

По итогам 02 решить, как устроен вход извне:

- `GApplication` с D-Bus-активацией или отдельный D-Bus-интерфейс;
- что делает `edge-notes new` / `edge-notes all`, если приложение не запущено;
- нужен ли CLI вообще, или достаточно `.desktop` с действиями;
- как команда фокусирует панель на Wayland (см. 02, вопрос 5).

## Answer

**CLI.** `lurknotes new` — новая заметка, `lurknotes all` — окно All Notes, без аргументов — показать колоду. Бинарник `lurknotes`, на время разработки ставится в `~/.local/bin`.

**Холодный старт.** Команда доводит действие до конца: приложение стартует и сразу открывает новую заметку с курсором. Второе нажатие не нужно.

**Фокус.** После активации через ~150 мс проверяем `is_active()`; если фокуса нет, панель показывает подсказку «Click to type», и клик по ней забирает ввод. Молча оставлять панель без фокуса нельзя: человек печатает и не понимает, почему буквы не появляются.

**Автостарт.** Включён в v1: `.desktop` в `~/.config/autostart`, приложение резидентно. Решение 08 в части автостарта пересмотрено: мгновенный доступ важнее экономии памяти.

**Повторные нажатия.** `new` при уже открытой нетронутой заметке фокусирует её, вторую не создаёт. `all` поднимает существующее окно All Notes, а не открывает второе.

**Имя.** **LurkNotes.** Бинарник `lurknotes`, application id `dev.lurknotes.LurkNotes`, данные в `~/.local/share/lurknotes/`, `.desktop` — `dev.lurknotes.LurkNotes.desktop`.
