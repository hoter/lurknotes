# Решение: редактор и заголовок

Type: grilling
Status: resolved

## Question

Насколько богатым должен быть текст и откуда берётся заголовок таба?

## Answer

Плоский текст + markdown-шорткаты: Ctrl+B/I оборачивают, `- `, `1. `, `[ ]` превращаются в списки на лету. В JSON — обычный текст, читаемый руками.

Заголовок таба = первая строка, отдельного поля нет; пустая заметка — «Untitled». Рич-текст с тегами отклонён на этом этапе.
