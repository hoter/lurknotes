# Модель взаимодействия колоды: состояния, hover, клик, перетаскивание

## Question

Спроектировать поведение колоды до уровня, по которому можно писать прототип. Нужны ответы на:

- Состояния: свёрнута (полоска) / развёрнута (веер) / заметка открыта / All Notes. Что происходит с колодой, когда открыта заметка — сворачивается, остаётся, прячется?
- Hover: наведение на полоску разворачивает веер мгновенно или с задержкой? Наведение на таб — «подглядывает» содержимое или подсвечивает? Клик по табу открывает заметку; что делает повторный клик?
- Уход мыши: сворачивать сразу, с задержкой, или при открытой заметке не сворачивать?
- Перетаскивание: таб тащится за заголовок, порядок сохраняется в JSON; что при перетаскивании за пределы колоды, анимация или мгновенно.
- Клавиатура: Esc в заметке, Tab между чем, фокус при открытии.
- «Новая заметка»: пустой таб сверху, панель сразу с курсором, автосохранение по вводу.
- Несколько заметок одновременно: одна панель или несколько; если одна — что при клике на другой таб.
- 30+ заметок: веер растягивается, прокручивается колесом, сжимается, показывает счётчик.

Завести `GLOSSARY.md` с терминами Deck, Tab, Strip, Peek, Note, All Notes, как только они устоятся.

## Answer

Колода имеет три состояния: `strip` (свёрнута) → `fan` (веер табов) → `panel` (заметка открыта). Открытая заметка не прячет табы: клик по другому табу подменяет содержимое панели, Esc возвращает в веер.

Два уровня наведения: указатель на полоске разворачивает веер (120 мс), указатель на табе разворачивает заметку на месте только для чтения — peek (150 мс, первые ~6 строк, без скролла). Сворачивание — через 400 мс после ухода указателя. Тайминги стартовые, прототип их подкручивает.

Одна панель на всё приложение; несколько панелей — возможное расширение, не часть v1.

Новая заметка появляется сверху колоды и сразу открывается панелью с курсором в пустом поле; сохранение — debounce ~400 мс плюс запись при закрытии. Судьба пустой заметки — в тикете 04.

Переполнение: веер прокручивается колесом, табы сохраняют полную высоту, на краях мягкое затухание; без сжатия и счётчиков.

Перетаскивание — за заголовок таба, пунктирный слот показывает место, отпускание вне колоды отменяет, порядок пишется в JSON при отпускании. Порядок в колоде и в All Notes — один массив.

Клавиатура в панели: Esc закрыть, Ctrl+Tab / Ctrl+Shift+Tab следующая/предыдущая заметка, Ctrl+Backspace удалить с undo, Ctrl+Z вернуть; клик по табу ставит курсор в редактор.

Словарь зафиксирован в `GLOSSARY.md`: Deck, Strip, Fan, Tab, Note, Peek, Panel, All Notes.
