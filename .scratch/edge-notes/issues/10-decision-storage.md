# Решение: хранение заметок

Type: grilling
Status: resolved

## Question

Где и в каком формате живут заметки?

## Answer

Один JSON в `~/.local/share/lurknotes/notes.json` (путь уточнён в 06, когда имя стало LurkNotes). Атомарная запись (временный файл + rename), бэкап предыдущей версии рядом. Ни SQLite, ни markdown-файл на заметку: обещание «заметки — обычный локальный файл» — часть продукта.

Поля и версия схемы уточняются в 04.
