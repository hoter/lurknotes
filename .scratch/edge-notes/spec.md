# LurkNotes — спека MVP

Версия 1.0. Дата: 2026-10-26. Платформа: Ubuntu 24.04, GNOME 46, Wayland-сессия.

Спека собрана из закрытых тикетов карты: [модель взаимодействия](issues/03-deck-interaction.md), [жизненный цикл заметки](issues/04-note-lifecycle.md), [прототип](issues/05-prototype-deck.md), [единый экземпляр](issues/06-single-instance.md), решения 08–10, 12–14, [research 01](research/01-layer-shell.md), [research 02](research/02-global-shortcut.md). Термины — в [GLOSSARY.md](../../GLOSSARY.md).

---

## 1. Что это

Заметки, которые живут колодой у правого края экрана. Наведение мыши разворачивает веер табов, наведение на таб показывает превью, клик открывает редактор, `Esc` возвращает обратно. Всё хранится в одном JSON на машине: без сети, аккаунтов и синхронизации.

Главный сценарий: `Ctrl+Alt+N` из любого приложения → курсор в пустой заметке → напечатал → ушёл. Колода остаётся у края и не мешает.

---

## 2. Границы v1

### Входит

- Колода у правого края: полоска, веер табов, peek.
- Одна панель редактора, переключение между заметками без закрытия.
- Окно All Notes со списком и поиском.
- Перетаскивание порядка, удаление с undo.
- Автосохранение в один JSON, бэкап, восстановление после порчи.
- CLI `lurknotes new|all` и `Ctrl+Alt+N` / `Ctrl+Alt+A` (привязка вручную).
- Автостарт, единый экземпляр, подсказка при отказе в фокусе.
- Тёмная тема, английский интерфейс.

### Не входит

Архив, цвета заметок, импорт/экспорт, portable-режим, светлая тема, второй монитор, i18n, рич-текст, ссылки, синхронизация, упаковка (flatpak/deb), GNOME Shell extension, переписывание на Rust.

## 3. Домен и состояния

Термины: **Deck**, **Strip**, **Fan**, **Tab**, **Peek**, **Panel**, **Note**, **All Notes**, **Untouched note** — см. глоссарий.

```
strip ──(hover полоски, 120 мс)──▶ fan
fan   ──(hover таба, 150 мс)────▶ peek внутри fan
fan   ──(клик по табу)──────────▶ open
open  ──(Esc / × в колонке)─────▶ fan
fan   ──(уход мыши, 400 мс)─────▶ strip
fan   ──(× в шапке)─────────────▶ strip
```

Правила:

- `open` не сворачивается сам: пока заметка открыта, панель остаётся, даже если мышь ушла.
- В `open` табы остаются видны узкой колонкой слева; клик по другому табу подменяет содержимое панели.
- Peek — только чтение; редактор открывается кликом.

## 4. Сценарии

### 4.1 Захват мысли

1. `Ctrl+Alt+N` в любом приложении (холодный старт — приложение поднимается).
2. Панель раскрывается, новая заметка сверху колоды, курсор в пустом поле.
3. Печать, автосохранение через 400 мс паузы.
4. `Esc` или `×` — вернуться к вееру; уход мыши сворачивает до полоски.

### 4.2 Вернуться к заметке

Навести на полоску → веер → навести на таб (превью) → клик → редактор с курсором в конце текста.

### 4.3 Найти заметку

`Ctrl+Alt+A` → All Notes → ввод в поиск → клик по результату → заметка открывается в панели, All Notes остаётся открытым.

### 4.4 Навести порядок

Зажать таб, потянуть вверх/вниз (курсор `grabbing`, таб приподнимается), отпустить. Порядок сразу пишется в файл и одинаков в колоде и All Notes.

### 4.5 Удалить и передумать

`Ctrl+Backspace` → заметка исчезает, тост «Deleted. 10s to undo» → `Ctrl+Z` или кнопка Undo возвращают её на прежнее место. Через 10 секунд отмена исчезает.

### 4.6 Первый запуск

Заметок нет: веер показывает пустое состояние и `+`. Один раз показывается подсказка, как привязать хоткеи: Настройки → Клавиатура → Собственные сочетания → команда `lurknotes new`. Факт показа отмечается файлом `onboarded` в каталоге данных.

## 5. Данные

### 5.1 Файл

`$XDG_DATA_HOME/lurknotes/notes.json` (по умолчанию `~/.local/share/lurknotes/notes.json`).

```json
{
  "version": 1,
  "notes": [
    {
      "id": "0f0c2f4e-6a1b-4c3d-9e8f-1a2b3c4d5e6f",
      "text": "Groceries\nmilk\neggs\nbread",
      "created": 1793025619.33,
      "updated": 1793025900.12
    }
  ]
}
```

- `id` — UUID4, строка.
- `text` — плоский текст, `\n` между строками.
- `created` / `updated` — Unix-время в секундах, float.
- Порядок заметок — **индекс в массиве**. Отдельного поля `order` нет.
- `color`, `archived`, `title` не хранятся: цвет и архив вне v1, заголовок вычисляется из текста.

### 5.2 Запись

1. Сериализовать в `notes.json.tmp`.
2. `fsync` файла.
3. Скопировать текущий `notes.json` в `notes.bak.json` (best effort).
4. `os.replace(tmp, notes.json)`.

Запись происходит: через 400 мс после последнего изменения, при переключении заметки, при закрытии панели, при выходе из приложения.

### 5.3 Восстановление

- JSON не парсится → читаем `notes.bak.json`; битый файл переименовываем в `notes.corrupt-<timestamp>.json` и показываем ошибку.
- Бэкап тоже битый → пустой список, ошибка, файл не перезаписываем до действия пользователя.
- `version` больше поддерживаемой → режим только чтения, ошибка, никаких записей.
- Каталог недоступен для записи → приложение работает в памяти, показывает «Save failed», повторяет запись.

### 5.4 Правила заметок

- Заголовок = первая непустая строка, обрезанная до 60 символов с многоточием. Пустая заметка — «Untitled».
- Дубли заголовков разрешены.
- Превью — до 6 строк после заголовка.
- **Untouched note** (текст пуст и `created == updated`) удаляется при закрытии, но только если создана в текущей сессии. При загрузке файла пустые заметки не удаляются.
- Удаление сразу пишется в файл; отмена живёт 10 секунд только в памяти. Закрытие приложения отмену теряет. Одновременно одна отложенная отмена: второе удаление фиксирует первое.

## 6. Интерфейс

Все размеры — логические пиксели, умножаются на масштаб GDK.

| Элемент | Размер | Положение |
|---|---|---|
| Strip | 10 × высота рабочей области | правый край |
| Fan | 380 × высота рабочей области | вплотную к полоске |
| Panel (note) | 380 × высота рабочей области | там же |
| Колонка табов в open | 112 шириной | слева в панели |
| All Notes | 720 × 560, изменяемое | по центру |

Верх окна — верх рабочей области (под топбаром GNOME), не `y=0`.

### 6.1 Полоска

Тёмная полоса 10 px, видна всегда, кроме полноэкранных приложений (их перекрывает). Служит и целью наведения, и индикатором, что приложение живо.

### 6.2 Веер

Шапка: «NOTES», кнопки `+` и `×`, подсказка «hover a note to peek · drag to reorder». Ниже — табы по порядку.

Таб: заголовок, при наведении раскрывается превью (до 6 строк, только чтение). Переполнение — колесо мыши прокручивает веер; табы не сжимаются.

### 6.3 Панель заметки

Слева колонка табов (112 px): `×` закрывает заметку, ниже — список всех заметок, активная подсвечена. Справа — `GtkTextView` на всю оставшуюся ширину.

Тост удаления — поверх панели снизу по центру, 10 секунд.

### 6.4 All Notes

Обычное окно. Сверху поиск и меню с «Quit LurkNotes». Список: заголовок, сниппет, дата изменения. Сортировка — ручной порядок. Клик открывает заметку в панели, окно не закрывается.

### 6.5 Тема

Тёмная, задаётся явно; `gtk-application-prefer-dark-theme` включён. Светлая — после MVP.

Палитра:

| Роль | Цвет |
|---|---|
| Фон окна | `#1c1c22` |
| Фон полоски | `#24242c` |
| Таб | `#2b2b35` |
| Таб под курсором | `#353542` |
| Таб при перетаскивании | `#3d3d4c` + тень |
| Колонка табов | `#17171d` |
| Текст | `#e9e9f1` |
| Второстепенный текст | `#a9a9b8` |
| Приглушённый текст | `#6f6f7e` |
| Тост | `#3a3a46` |

## 7. Взаимодействие

### 7.1 Тайминги

| Событие | Задержка |
|---|---|
| Наведение на полоску → веер | 120 мс |
| Наведение на таб → peek | 150 мс |
| Уход мыши → сворачивание | 400 мс |
| Автосохранение | 400 мс после последнего ввода |
| Отмена удаления | 10 000 мс |
| Проверка фокуса после активации | 150 мс |

### 7.2 Мышь

- Клик по табу — открыть заметку; смещение меньше 5 px считается кликом, больше — перетаскиванием. Отдельного клик-жеста нет: в GTK4 `GestureDrag` забирает нажатие и отменяет `GestureClick`.
- Курсор на табе — `grab`, при перетаскивании — `grabbing`.
- Перетаскивание: таб приподнимается (тень, светлее фон), порядок пишется при отпускании. Отпускание вне колоды отменяет перестановку.
- Колесо мыши над веером — прокрутка списка табов.

### 7.3 Клавиатура

| Клавиши | Действие |
|---|---|
| `Esc` | закрыть заметку; если заметка не открыта — свернуть панель |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | следующая / предыдущая заметка |
| `Ctrl+Backspace` | удалить заметку с undo |
| `Ctrl+Z` | вернуть удалённую (пока тост жив) |
| `Ctrl+B` / `Ctrl+I` | обернуть выделение `**` / `*` |
| `- `, `1. `, `[ ]` + пробел | маркированный, нумерованный, чеклист |
| `Backspace` сразу после маркера | вернуть строку как была |
| `Enter` в списке | продолжить список |

`Esc` работает только когда панель в фокусе (после клика). Кнопки `×` существуют именно потому, что наведение фокус не забирает.

### 7.4 Сворачивание

`fan → strip` по уходу мыши, по `×` в шапке или по `Esc` при фокусе. Панель размапливается (см. ограничения).

## 8. Редактор

- Плоский текст; в файле — обычный текст, не разметка.
- Заголовок не редактируется отдельно: первая строка и есть заголовок.
- Новая заметка открывается с курсором в пустом поле; существующая — с курсором в конце текста.
- Автосохранение по паузе; при неудаче — индикатор «Save failed» и повтор.
- Ссылки, картинки, вставка форматированного текста — вне v1.

## 9. Интеграция с системой

### 9.1 Окна

Приложение — X11-клиент под XWayland (`GDK_BACKEND=x11` до импорта GTK). Это вынужденно: Mutter 46 не реализует `zwlr_layer_shell_v1`, а обычное Wayland-окно нельзя прижать к краю, поднять поверх и убрать из дока.

Для полоски и панели:

- без декораций, не изменяемые пользователем;
- `_NET_WM_STATE_ABOVE`, `_NET_WM_STATE_SKIP_TASKBAR`, `_NET_WM_STATE_STICKY`, `_NET_WM_DESKTOP = 0xFFFFFFFF`;
- позиция и размер — через X11 с умножением логических размеров на масштаб;
- пока панель не в режиме редактирования: `WM_HINTS.input = False` и `_NET_WM_USER_TIME = 0`, чтобы появление панели не крало клавиатуру;
- при открытии заметки ограничения снимаются и вызывается `present()`.

### 9.2 Хоткеи

На GNOME 46 портала `GlobalShortcuts` нет, поэтому приложение не регистрирует хоткеи само. Пользователь создаёт два собственных сочетания в настройках GNOME:

| Комбинация | Команда |
|---|---|
| `Ctrl+Alt+N` | `lurknotes new` |
| `Ctrl+Alt+A` | `lurknotes all` |

Инструкция показывается при первом запуске и лежит в README.

### 9.3 CLI и единый экземпляр

- `lurknotes new` — новая заметка и открыть её.
- `lurknotes all` — открыть All Notes.
- без аргументов — развернуть веер.
- Бинарник `lurknotes` (`~/.local/bin` при разработке), application id `dev.lurknotes.LurkNotes`.
- Второй процесс не запускается: `Gtk.Application` + `Gio.ApplicationFlags.HANDLES_COMMAND_LINE` передаёт argv первому экземпляру.
- Холодный старт доводит действие до конца: нажал `Ctrl+Alt+N` — приложение поднялось и открыло заметку.

Повторные нажатия: `new` при открытой нетронутой заметке фокусирует её, вторую не создаёт; `all` поднимает существующее окно All Notes.

### 9.4 Автостарт

`~/.config/autostart/dev.lurknotes.LurkNotes.desktop`, запуск в фоне: видна только полоска, фокус не забирается.

### 9.5 Фокус

Наведение фокус не забирает никогда. После `new`/`all` приложение пытается активироваться; если через 150 мс `is_active()` всё ещё false, панель показывает подсказку «Click to type», и первый клик забирает ввод. Молча оставлять панель без фокуса нельзя.

## 10. Ошибки и краевые случаи

| Ситуация | Поведение |
|---|---|
| Битый JSON | загрузить `notes.bak.json`, битый сохранить как `notes.corrupt-<ts>.json`, показать ошибку |
| Неизвестная версия файла | только чтение, ошибка, не перезаписывать |
| Нет прав на запись | работать в памяти, «Save failed», повторять |
| Нет X-дисплея / XWayland выключен | выйти с понятным сообщением |
| Фокус не дан | подсказка «Click to type» |
| Хоткей не привязан | приложение работает, первый запуск объясняет привязку |
| Пустая заметка закрыта | удалить, если она нетронутая и создана в этой сессии |
| Удалено во время тоста | второе удаление фиксирует первое, тост перезапускается |

## 11. Нефункциональные требования

- Холодный старт — до 1.5 с, тёплый — до 300 мс.
- Простой CPU — около нуля, без опроса и таймеров в фоне.
- Память в простое — до 120 МБ (цель); если не выходит, это аргумент за Rust.
- Ноль сетевых запросов и телеметрии.
- `kill -9` в момент сохранения не должен портить файл (атомарная замена).
- Никаких записей вне `$XDG_DATA_HOME` и `~/.config`.

## 12. Критерии готовности MVP

1. После логина полоска видна у правого края; в доке и Alt+Tab приложения нет.
2. Наведение разворачивает веер, уход сворачивает, `Esc` после клика закрывает.
3. Peek появляется через 150 мс и не мигает при проходе мышью.
4. Клик открывает заметку, ввод доходит до редактора, текст сохраняется через 400 мс.
5. `Ctrl+Alt+N` из другого приложения создаёт заметку и на холодном, и на тёплом старте.
6. Удаление с undo работает 10 секунд; после перезапуска отмены нет.
7. Перетаскивание меняет порядок; порядок одинаков в колоде и All Notes.
8. Поиск находит заметку по подстроке в любом месте текста.
9. `Ctrl+Alt+A` открывает All Notes; клик по результату открывает панель.
10. Битый JSON восстанавливается из бэкапа.
11. Полноэкранное приложение перекрывает колоду (ожидаемо).
12. Светлых вспышек и белых областей при открытии панели нет.

## 13. Известные ограничения платформы

- **Layer-shell недоступен.** Mutter 46 не реализует протокол; «у края поверх всех» достигнуто только через XWayland и EWMH.
- **Полноэкранные приложения перекрывают колоду.** Принято: так и должно быть.
- **Дробное масштабирование** может мылить текст: приложение — X11-клиент.
- **Сворачивание размапливает панель**, и GNOME передаёт фокус полоске. Если в этот момент печатать в другом окне, ввод может потеряться. В v1 принято; альтернатива — держать панель замапленной с прозрачностью и input-shape — вне v1.
- **Окно начинается под топбаром** GNOME (y = 32 логических px), а не от края экрана.
- Проверено только на GNOME 46 / Ubuntu 24.04. Другие оболочки и версии не тестировались.

## 14. Грабли, уже собранные прототипом

Чтобы не наступить второй раз:

- PyGObject 3.48: `GObject.set_data/get_data` не работают — только обычные атрибуты Python.
- GTK4 `GestureDrag` забирает последовательность по нажатию и отменяет `GestureClick`; клик и перетаскивание различаются одним жестом по смещению 5 px.
- `ScrolledWindow` не растягивается без явных `hexpand`/`vexpand`.
- CSS-класс, объявленный но не повешенный, не действует: окно остаётся в светлой теме.
- X11-координаты физические: логические размеры умножаются на `scale`.
- Mutter прижимает окна к рабочей области — трюк «увести панель за экран» не работает.
- `Gdk.Monitor.get_workarea` в PyGObject 3.48 нет; высота окна берётся из фактической аллокации GTK (928 при экране 960).
- `_NET_WM_USER_TIME = 0` заставляет Mutter не фокусировать окно при появлении (ценой `DEMANDS_ATTENTION`, что без иконки в доке не видно).

## 15. Что дальше (после MVP)

Архив, цвета, импорт/экспорт, portable, светлая тема, второй монитор, упаковка в flatpak, локализация, возможный переход на Rust — отдельные усилия. UI-полировка (анимации, типографика) тоже за краем этой спеки.
