# LurkNotes — план реализации MVP

Источник: [spec.md](spec.md). План не добавляет решений — только порядок работ и проверки. Если по ходу выяснится, что спека врёт, правим спеку, а не молча код.

## Принципы

1. **Данные важнее интерфейса.** Слой хранения и его тесты идут раньше любой красоты: заметки — единственное, что нельзя восстановить.
2. **Сначала риски, потом объём.** Всё, что может обнулить архитектуру (фокус по внешнему вызову, автостарт, EWMH), проверяется спайками до того, как на этом начнёт расти UI.
3. **Прототип — источник грабель, не код.** `.scratch/edge-notes/prototype/` не переносится; из него берутся только проверенные приёмы (EWMH-хинты, один жест на клик/драг, hexpand).
4. **Каждый шаг проверяем.** Либо тест, либо скрипт, либо пункт приёмки — «выглядит нормально» не считается.

## Структура проекта

```
lurknotes/                  репозиторий
├── lurknotes               исполняемый скрипт (symlink в ~/.local/bin)
├── pyproject.toml          метаданные, зависимости (PyGObject системный)
├── src/lurkn/
│   ├── __main__.py         точка входа: GDK_BACKEND, argv, app.run
│   ├── app.py              Gtk.Application, единый экземпляр, команды
│   ├── x11.py              EWMH-хинты, позиционирование, фокус, указатель
│   ├── store.py            JSON, атомарная запись, бэкап, восстановление
│   ├── notes.py            модель заметки, заголовок/превью, порядок
│   ├── strings.py          все строки UI в одном месте
│   ├── windows/
│   │   ├── strip.py        полоска
│   │   ├── panel.py        панель: веер ↔ заметка
│   │   └── all_notes.py    окно All Notes
│   └── ui/
│       ├── fan.py          веер, табы, peek, drag
│       ├── note.py         панель заметки: рейл + редактор
│       └── theme.css       тёмная тема, палитра из спеки
├── tests/
│   ├── test_store.py
│   └── test_notes.py
└── scripts/
    └── smoke.py            запуск приложения + проверка окон через X11
```

Тесты — `pytest`, только не-GUI части. UI проверяется `scripts/smoke.py` и ручной приёмкой.

## Спайки (до основного кода)

Три вопроса, каждый — отдельный маленький скрипт, не больше сотни строк. Если ответ «нет», меняем спеку, пока не поздно.

- [ ] **Спайк A: фокус по внешнему вызову.** `Gtk.Application` + `HANDLES_COMMAND_LINE`, окно без декораций. Второй процесс вызывает `new`. Проверить: приходит ли команда, поднимается ли окно, становится ли `is_active()` true после `present()` без клика. Если нет — включаем подсказку «Click to type» и фиксируем в спеке, что автофокус недостижим.
- [ ] **Спайк B: автостарт.** `.desktop` в `~/.config/autostart`, логин в Wayland-сессию. Проверить: процесс жив, полоска видна, фокус не украден, второй экземпляр не стартует.
- [ ] **Спайк C: масштаб.** Позиционирование при `GDK_SCALE=1` и текущем 2. Если при 1 ломается — правка в `x11.py`, пока он не оброс логикой.

## M0. Каркас

**Цель:** приложение запускается, показывает полоску и пустую панель у правого края, живёт в трее окон правильно.

- [ ] `git init`, `.gitignore` (`__pycache__`, `.venv`), README с запуском.
- [ ] `pyproject.toml`, скрипт `lurknotes`, symlink в `~/.local/bin`.
- [ ] `__main__.py`: `GDK_BACKEND=x11` до импорта GTK, разбор `new|all`, без аргументов — веер.
- [ ] `x11.py`: EWMH-хинты, `move_resize(win, logical_w, offset)`, `pointer()`, `set_input`, `set_no_focus`.
- [ ] `windows/strip.py`, `windows/panel.py`: без декораций, `ABOVE`/`SKIP_TASKBAR`/`STICKY`, позиция по спеке.
- [ ] `scripts/smoke.py`: поднимает приложение, ждёт два окна, проверяет хинты и геометрию, выходит 0/1.

**Готово, когда:** `smoke.py` зелёный; в доке и Alt+Tab приложения нет; полоска 10 px у правого края.

## M1. Хранение

**Цель:** заметки переживают `kill -9`, порчу файла и неизвестную версию.

- [ ] `notes.py`: `Note`, `title()`, `preview()`, `is_untouched()`, операции add/delete/move/update.
- [ ] `tests/test_store.py`: round-trip, бэкап, битый JSON, битый бэкап, неизвестная версия, отсутствие прав.

## Риски

| Риск | Когда снимаем | Что делаем, если сработал |
|---|---|---|
| Фокус по хоткею не даётся | Спайк A | Подсказка «Click to type» как штатный путь, а не костыль |
| Автостарт крадёт фокус при логине | Спайк B | Запуск скрытым, `_NET_WM_USER_TIME=0` |
| EWMH ведёт себя иначе после обновления GNOME | M0, M8 | Проверка в `smoke.py`, запасной путь — GNOME Shell extension (вне MVP) |
| Python не укладывается в бюджет | M8 | Замер и решение про Rust, не «потерпим» |
| XWayland отключат | — | Вне контроля; тогда единственный путь — extension |

## Что не входит в план

Архив, цвета, импорт/экспорт, portable, светлая тема, второй монитор, упаковка, локализация, Rust — отдельные усилия после MVP.
