# 02: Одна заметка — из файла до редактора

**What to build:** Приложение читает заметки из JSON, показывает их в веере, по клику открывает панель с текстом, и всё, что напечатано, сохраняется на диск. Это первый полный путь через все слои: файл → список → редактор → файл.

**Blocked by:** 01

**Triage:** ready-for-agent
**Status:** resolved

- [x] JSON схемы спеки читается; при отсутствии файла список пуст, файл создаётся при первой заметке.
- [x] Заметки видны в веере в порядке массива; заголовок таба — первая непустая строка.
- [x] Клик по табу открывает панель с текстом, курсор в конце текста.
- [x] Ввод сохраняется через 400 мс после паузы и при закрытии панели; после перезапуска текст на месте.
- [x] Запись атомарная: `kill -9` во время сохранения не портит файл.
- [x] Предыдущая версия файла сохраняется как `notes.bak.json`.
- [x] Тесты store: round-trip, бэкап, отсутствие файла, запись поверх существующего.

## Answer

Реализовано: `Store` читает/пишет JSON версии 1 в `$XDG_DATA_HOME/lurknotes/notes.json`; отсутствие файла даёт пустую колоду (восстановление из бэкапа — только по маркеру `notes.recovering` после прерванного recovery). Запись атомарная: tmp+fsync → бэкап → `os.replace` → fsync каталога; `notes.bak.json` хранит предыдущую валидную версию. Веер показывает заметки в порядке массива, клик открывает панель с курсором в конце, автосохранение 400 мс + flush при переключении/закрытии/выходе. Evidence: `tests/test_store.py`, `scripts/smoke_note.py`, `scripts/acceptance.py`.
