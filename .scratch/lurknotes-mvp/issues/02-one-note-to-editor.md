# 02: Одна заметка — из файла до редактора

**What to build:** Приложение читает заметки из JSON, показывает их в веере, по клику открывает панель с текстом, и всё, что напечатано, сохраняется на диск. Это первый полный путь через все слои: файл → список → редактор → файл.

**Blocked by:** 01

**Triage:** ready-for-agent
**Status:** open

- [ ] JSON схемы спеки читается; при отсутствии файла список пуст, файл создаётся при первой заметке.
- [ ] Заметки видны в веере в порядке массива; заголовок таба — первая непустая строка.
- [ ] Клик по табу открывает панель с текстом, курсор в конце текста.
- [ ] Ввод сохраняется через 400 мс после паузы и при закрытии панели; после перезапуска текст на месте.
- [ ] Запись атомарная: `kill -9` во время сохранения не портит файл.
- [ ] Предыдущая версия файла сохраняется как `notes.bak.json`.
- [ ] Тесты store: round-trip, бэкап, отсутствие файла, запись поверх существующего.
