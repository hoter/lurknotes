# 09: Интеграция — CLI, автостарт, фокус

**What to build:** Приложение вызывается из любого места командой и хоткеем, живёт после логина и честно ведёт себя, когда система не даёт ему клавиатуру.

**Blocked by:** 03, 04

**Triage:** ready-for-agent
**Status:** open

- [ ] `lurknotes new` создаёт заметку, `lurknotes all` открывает All Notes, без аргументов разворачивает веер.
- [ ] Второй экземпляр не запускается: аргументы передаются уже работающему процессу.
- [ ] Холодный старт доводит действие до конца: команда создаёт заметку и открывает её.
- [ ] `new` при уже открытой нетронутой заметке фокусирует её, а не создаёт вторую; `all` поднимает существующее окно.
- [ ] Автостарт через `~/.config/autostart`: после логина видна только полоска, фокус не украден, второй экземпляр не стартует.
- [ ] Если через 150 мс после активации фокуса нет, панель показывает «Click to type», и первый клик забирает ввод.
- [ ] Первый запуск показывает инструкцию по привязке `Ctrl+Alt+N` / `Ctrl+Alt+A` и больше её не повторяет.
