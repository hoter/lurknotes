**Blocked by:** 03, 04

**Triage:** ready-for-agent
**Status:** resolved

- [x] `lurknotes new` создаёт заметку, `lurknotes all` открывает All Notes, без аргументов разворачивает веер.
- [x] Второй экземпляр не запускается: аргументы передаются уже работающему процессу.
- [x] Холодный старт доводит действие до конца: команда создаёт заметку и открывает её.

- [x] Автостарт через `~/.config/autostart`: файл и `--autostart` проверены (только полоска, фокус не украден, второй экземпляр не стартует); реальный relogin не прогонялся.
- [x] Если через 150 мс после активации фокуса нет, панель показывает «Click to type», и первый клик забирает ввод.

## Answer

Реализовано: `HANDLES_COMMAND_LINE` + `do_command_line`; `new` создаёт/открывает, `all` открывает/поднимает All Notes, без аргументов веер разворачивается сразу, `--autostart` — только полоска, `--install-autostart` пишет `.desktop`. Второй процесс передаёт argv первому и выходит; холодный старт доводит действие до конца; `new` переиспользует открытую нетронутую заметку. Фокус: 150 мс проверка `_NET_ACTIVE_WINDOW`, `Click to type`, первый клик забирает ввод; онбординг один раз по маркеру `onboarded`. Отклонение: реальный logout/login и привязка хоткеев в GNOME Settings — ручные шаги; проверены файл автостарта и командный путь. Evidence: `tests/test_cli.py`, `tests/test_focus.py`, `tests/test_onboarding.py`, `tests/test_autostart.py`, `scripts/smoke_integration.py`.
