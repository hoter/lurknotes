# 08: Надёжность хранения

**What to build:** Испорченный файл не уносит заметки: приложение восстанавливается из бэкапа, не перезаписывает незнакомую версию и честно говорит, если записать не удалось.

**Blocked by:** 02

**Triage:** ready-for-agent
**Status:** open

- [ ] Битый JSON: загружается `notes.bak.json`, битый файл сохраняется как `notes.corrupt-<ts>.json`, пользователь видит ошибку.
- [ ] Битый бэкап: пустой список, ошибка, исходный файл не перезаписывается до действия пользователя.
- [ ] `version` больше поддерживаемой: режим только чтения, ошибка, никаких записей.
- [ ] Нет прав на запись: приложение работает в памяти, показывает «Save failed» и повторяет запись.
- [ ] Тесты покрывают каждую ветку восстановления.
