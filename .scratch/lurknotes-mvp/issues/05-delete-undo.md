# 05: Удаление с undo

**What to build:** Заметку можно удалить одной комбинацией и вернуть в течение десяти секунд. Удаление сразу попадает в файл, отмена живёт только пока приложение открыто.

**Blocked by:** 03

**Triage:** ready-for-agent
**Status:** open

- [ ] `Ctrl+Backspace` удаляет заметку и сразу пишет файл.
- [ ] Появляется тост «Deleted. 10s to undo» с кнопкой Undo.
- [ ] `Ctrl+Z` и кнопка Undo возвращают заметку на прежнее место.
- [ ] Через 10 секунд отмена исчезает; после перезапуска приложения отмены нет.
- [ ] Второе удаление фиксирует первое, тост начинается заново.
- [ ] Удаление последней заметки показывает пустое состояние, приложение не падает.
