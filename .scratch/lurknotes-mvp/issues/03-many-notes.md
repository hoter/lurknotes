# 03: Несколько заметок и правила жизни

**What to build:** Заметок может быть много: их можно создавать, переключать, редактировать и закрывать, а пустые нетронутые исчезают сами. Заголовки и превью ведут себя по спеке.

**Blocked by:** 02

**Triage:** ready-for-agent
**Status:** open

- [ ] `+` создаёт заметку сверху колоды и сразу открывает её с курсором в пустом поле.
- [ ] В панели есть колонка табов; активная подсвечена; клик переключает заметку.
- [ ] `Ctrl+Tab` / `Ctrl+Shift+Tab` листают заметки без мыши.
- [ ] Заголовок — первая непустая строка, обрезанная до 60 символов с многоточием; пустая заметка — «Untitled».
- [ ] Превью показывает до 6 строк после заголовка.
- [ ] Нетронутая пустая заметка удаляется при закрытии; при загрузке файла пустые заметки не удаляются.
- [ ] Одинаковые заголовки разрешены и не ломают список.
