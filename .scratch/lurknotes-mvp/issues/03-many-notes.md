# 03: Несколько заметок и правила жизни

**What to build:** Заметок может быть много: их можно создавать, переключать, редактировать и закрывать, а пустые нетронутые исчезают сами. Заголовки и превью ведут себя по спеке.

**Blocked by:** 02

**Triage:** ready-for-agent
**Status:** resolved

- [x] `+` создаёт заметку сверху колоды и сразу открывает её с курсором в пустом поле.
- [x] В панели есть колонка табов; активная подсвечена; клик переключает заметку.
- [x] `Ctrl+Tab` / `Ctrl+Shift+Tab` листают заметки без мыши.
- [x] Заголовок — первая непустая строка, обрезанная до 60 символов с многоточием; пустая заметка — «Untitled».
- [x] Превью показывает до 6 строк после заголовка.
- [x] Нетронутая пустая заметка удаляется при закрытии; при загрузке файла пустые заметки не удаляются.
- [x] Одинаковые заголовки разрешены и не ломают список.

## Answer

Реализовано: `+` создаёт заметку сверху и открывает её с курсором в пустом поле; новая заметка не пишется на диск до текста/переключения/закрытия/выхода (спека §5.2). Рейл 112 px с активной подсветкой, `Ctrl+Tab`/`Ctrl+Shift+Tab` с заворотом. Заголовок — первая непустая строка, 60 символов с `…`, пустая — `Untitled`; превью — до 6 строк; дубликаты заголовков разрешены. Нетронутая заметка удаляется при закрытии/переключении/выходе, загруженные пустые сохраняются. Evidence: `tests/test_notes.py`, `tests/test_command_new.py`, `scripts/smoke_note.py`.
