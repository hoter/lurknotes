# 04: Наведение, peek и сворачивание

**What to build:** Колода ведёт себя как колода: полоска разворачивается от наведения, таб показывает превью, уход мыши сворачивает, а открытая заметка не исчезает. Тёмная тема без белых участков.

**Blocked by:** 03

**Triage:** ready-for-agent
**Status:** open

- [ ] Наведение на полоску разворачивает веер примерно за 120 мс.
- [ ] Наведение на таб примерно через 150 мс показывает превью только для чтения; проход мышью не вызывает мигания.
- [ ] Уход мыши сворачивает веер примерно за 400 мс.
- [ ] Открытая заметка не сворачивается сама; `Esc` закрывает её, повторный `Esc` сворачивает панель.
- [ ] `×` в шапке веера сворачивает панель без необходимости фокуса.
- [ ] Колесо мыши прокручивает веер; табы не сжимаются.
- [ ] Окно и все поверхности тёмные: ни белых областей, ни светлых вспышек при открытии.
