# 04: Наведение, peek и сворачивание

**What to build:** Колода ведёт себя как колода: полоска разворачивается от наведения, таб показывает превью, уход мыши сворачивает, а открытая заметка не исчезает. Тёмная тема без белых участков.

**Blocked by:** 03

**Triage:** ready-for-agent
**Status:** resolved

- [x] Наведение на полоску разворачивает веер примерно за 120 мс.
- [x] Наведение на таб примерно через 150 мс показывает превью только для чтения; проход мышью не вызывает мигания.
- [x] Уход мыши сворачивает веер примерно за 400 мс.
- [x] Открытая заметка не сворачивается сама; `Esc` закрывает её, повторный `Esc` сворачивает панель.
- [x] `×` в шапке веера сворачивает панель без необходимости фокуса.
- [x] Колесо мыши прокручивает веер; табы не сжимаются.
- [x] Окно и все поверхности тёмные: ни белых областей, ни светлых вспышек при открытии.

## Answer

Реализовано: старт — только полоска; hover 120 мс → веер, 150 мс → peek, уход 400 мс → сворачивание; открытая заметка не сворачивается, `Esc`/`×` работают. Peek — фиксированная read-only панель внутри веера (не пятое окно); при переходе между табами старое превью остаётся до замены, панель не пустеет. Hover не забирает фокус; remap заново применяет EWMH/позицию. Отклонения: peek не разворачивает сам таб; пока жив undo-тост, панель принудительно остаётся замапленной до 10 с. Evidence: `tests/test_deck.py`, `scripts/smoke_hover.py`.
