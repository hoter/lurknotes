# 06: Перетаскивание порядка

**What to build:** Порядок заметок задаётся перетаскиванием таба и сохраняется. Жест не мешает обычному клику, который открывает заметку.

**Blocked by:** 03

**Triage:** ready-for-agent
**Status:** resolved

- [x] Один жест различает клик и перетаскивание: смещение меньше 5 px — клик, больше — drag.
- [x] Курсор на табе — `grab`, при перетаскивании — `grabbing`.
- [x] Таб при перетаскивании приподнимается: светлее фон и тень.
- [x] Порядок меняется при отпускании и сразу пишется в файл.
- [x] Отпускание вне колоды отменяет перестановку.
- [x] Новый порядок переживает перезапуск приложения.

## Answer

Реализовано: один `GestureDrag` на таб, <5 px — клик, ≥5 px — drag; курсор `grab`/`grabbing`, поднятый таб `#3d3d4c` + тень. Цель считается по фактическим границам строк, порядок меняется при отпускании и сразу пишется, `deck_changed()` обновляет All Notes; порядок переживает перезапуск. Отпускание вне зоны сброса (в т.ч. над 10 px полоской) отменяет; drag не сворачивает колоду. Evidence: `tests/test_reorder.py`, `scripts/smoke_drag.py`.
