# 07: All Notes и поиск

**What to build:** Отдельное окно показывает все заметки в ручном порядке и ищет по тексту. Из результата можно сразу открыть заметку у края.

**Blocked by:** 03

**Triage:** ready-for-agent
**Status:** open

- [ ] Окно 720×560, обычное, изменяемое, с меню «Quit LurkNotes».
- [ ] Список: заголовок, сниппет, дата изменения; порядок совпадает с колодой.
- [ ] Поиск — подстрока без учёта регистра по всему тексту; пустой запрос показывает всё.
- [ ] Результат показывает заголовок и строку с совпадением.
- [ ] Клик открывает заметку в панели, окно All Notes остаётся открытым.
- [ ] Изменения, сделанные в панели, сразу видны в списке.
