# 07: All Notes и поиск

**What to build:** Отдельное окно показывает все заметки в ручном порядке и ищет по тексту. Из результата можно сразу открыть заметку у края.

**Blocked by:** 03

**Triage:** ready-for-agent
**Status:** resolved

- [x] Окно 720×560, обычное, изменяемое, с меню «Quit LurkNotes».
- [x] Список: заголовок, сниппет, дата изменения; порядок совпадает с колодой.
- [x] Поиск — подстрока без учёта регистра по всему тексту; пустой запрос показывает всё.
- [x] Результат показывает заголовок и строку с совпадением.
- [x] Клик открывает заметку в панели, окно All Notes остаётся открытым.
- [x] Изменения, сделанные в панели, сразу видны в списке.

## Answer

Реализовано: обычное окно All Notes 720×560, изменяемое, по центру, с меню `Quit LurkNotes`; список в ручном порядке с заголовком, сниппетом и датой; поиск — регистронезависимая подстрока по всему тексту, пустой запрос показывает всё, строка совпадения подсвечивается. Клик открывает заметку в панели, окно остаётся; изменения из панели приходят через `DeckChanged` (включая текст до debounce). Evidence: `tests/test_all_notes.py`, `scripts/smoke_all_notes.py`.
