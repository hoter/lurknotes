# LurkNotes

Заметки, которые живут колодой у края экрана Linux-десктопа. Контекст описывает предметную область приложения, а не его реализацию.

## Language

**Deck**:
Колода целиком: полоска у края экрана и разворачивающийся из неё веер табов.
_Avoid_: Sidebar, dock

**Strip**:
Свёрнутое состояние колоды — узкая полоса у края экрана, за которую цепляется указатель.
_Avoid_: Handle, edge, tab bar

**Fan**:
Развёрнутое состояние колоды, в котором видны табы заметок.
_Avoid_: Drawer, list, overlay

**Tab**:
Корешок одной заметки в веере. Заголовок таба — первая строка заметки.
_Avoid_: Card, chip, item

**Note**:
Одна заметка: текст, цвет и позиция в порядке колоды.
_Avoid_: Memo, card, document

**Untouched note**:
Новая заметка, в которую ещё ничего не написали; удаляется при закрытии, а не остаётся пустой.
_Avoid_: Empty note, draft

**Peek**:
Разворот заметки на месте, в веере, только для чтения; редактор при этом не открывается.
_Avoid_: Preview, tooltip, hover

**Panel**:
Открытая заметка с редактором и фокусом клавиатуры. В v1 панель одна.
_Avoid_: Window, editor, note view

**All Notes**:
Отдельное окно со списком всех заметок и поиском.
_Avoid_: Manager, library, dashboard
