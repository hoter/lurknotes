# LurkNotes

Заметки-колода у края экрана для Ubuntu 24.04 / GNOME 46. Спека MVP — [spec.md](.scratch/edge-notes/spec.md), план реализации — [plan.md](.scratch/edge-notes/plan.md).

## Agent skills

### Issue tracker

Issues, specs and plans live as local markdown under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles on a `Triage:` line (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the repo root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
